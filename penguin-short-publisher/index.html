Penguin Short Publisher

A secure internal web tool used by Penguin Music Studio to connect an authorized TikTok account and publish original short-form music videos through TikTok's official developer APIs.

01

Connect

Authorized studio operators connect TikTok using TikTok's OAuth authorization flow. TikTok passwords are never collected by Penguin Short Publisher.

02

Prepare

The studio reviews the original video, caption, privacy settings, and publishing metadata before a post is submitted.

03

Publish

The tool submits approved short-form content to TikTok using the Content Posting API and records publishing status for studio operations.

Access is restricted. Penguin Short Publisher is not a public consumer application. It is an internal publishing workflow for Penguin Music Studio and is intended only for authorized studio operators and TikTok accounts they are permitted to manage.
